# visakk.github.io

Personal website of Visak Kumar, served by GitHub Pages at https://visakk.github.io/.

- `index.html`: the whole site (static, no build step)
- `assets/img/`: profile photo
- `assets/projects/`: looping project clips (MP4) and their poster frames
- `assets/cv/`: CV (PDF)
- `resume/`, `projects/`, `publications/`, `contact/`: redirects from the old site's paths to the matching section

Project pages live in their own repositories and are served under this domain, e.g.
https://visakk.github.io/pose-is-not-support/.
